# 📒 দোকান খাতা

বিকাশ, নগদ, রকেট, উপায় এবং মোবাইল রিচার্জ (গ্রামীণফোন, রবি, এয়ারটেল, বাংলালিংক, টেলিটক) দোকানের ডিজিটাল হিসাবের খাতা।
খাতা-কলম ছাড়াই সব হিসাব — যোগ-বিয়োগ, কমিশন, বাকি সব অটোমেটিক।

## কী কী আছে
- **হোম:** মোট সম্পদ, আজকের লাভ, প্রতিটি অ্যাকাউন্টের ব্যালেন্স
- **লেনদেন:** ক্যাশ ইন, ক্যাশ আউট, রিচার্জ, ব্যালেন্স কেনা/ফেরত (B2B), খরচ, অন্যান্য আয়, মূলধন
- **অটো হিসাব:** টাকা লিখলেই ব্যালেন্স, ক্যাশ ও কমিশন নিজে হিসাব হয়
- **বাকির খাতা:** কাস্টমার অনুযায়ী বাকি, আদায়, ইতিহাস, সরাসরি কল
- **রিপোর্ট:** দিন / সপ্তাহ / মাসের কমিশন, খরচ, নিট লাভ
- **হিসাব মিলানো:** দিন শেষে আসল ব্যালেন্স লিখলে পার্থক্য ঠিক করে দেয়
- **ব্যাকআপ ও এক্সেল (CSV) ফাইল, পিন লক, ডার্ক মোড, ইন্টারনেট ছাড়াও চলে**

## চালু করার নিয়ম (GitHub Pages)
1. GitHub-এ এই রিপোজিটরিতে যান → **Settings** → **Pages**
2. **Source:** `Deploy from a branch` বাছুন
3. **Branch:** যে ব্রাঞ্চে অ্যাপের ফাইল আছে সেটি ও `/ (root)` বেছে **Save** দিন
4. ১–২ মিনিট পর উপরে একটি লিংক দেখাবে (`https://<আপনার-ইউজারনেম>.github.io/<রিপোর-নাম>/`)

## ফোনে অ্যাপ হিসেবে ইন্সটল
1. ফোনের **Google Chrome**-এ লিংকটি খুলুন
2. উপরের ডান কোণে **⋮** মেনু → **Add to Home screen / অ্যাপ ইন্সটল করুন**
3. এখন হোম স্ক্রিনের আইকন থেকে সাধারণ অ্যাপের মতো খুলবে — ইন্টারনেট ছাড়াও

## জরুরি কথা
- সব হিসাব **শুধু আপনার ফোনেই** থাকে, কোথাও পাঠানো হয় না।
- তাই ব্রাউজারের ডেটা মুছলে বা ফোন নষ্ট হলে হিসাব হারাবে — নিয়মিত **আরও → ব্যাকআপ নিন** থেকে ফাইল সেভ করে রাখুন।
- কমিশনের রেট আনুমানিক দেওয়া আছে; **আরও → অ্যাকাউন্ট ও কমিশন রেট** থেকে নিজের আসল রেট বসিয়ে নিন।
